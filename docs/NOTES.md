## Challenges and Solutions

During the deployment process, several challenges were encountered:

### Docker Build Issues
At first, the Docker image did not build correctly due to missing dependencies.
This issue was resolved by updating the Dockerfile and ensuring all required packages were installed.

### Port Mapping Confusion
The application did not open in the browser initially because of incorrect port mapping.
This was resolved by mapping port 80 inside the container to port 8080 on the host machine.

### Codespaces URL Behavior
The forwarded URL generated by GitHub Codespaces changes after restarting the environment.
This was understood as normal behavior and documented accordingly in this notes file.





## Notes about Production URL

The application was deployed using Docker inside GitHub Codespaces.

The production URL is automatically generated by GitHub Codespaces and may change every time the container or Codespace is restarted.

Because of this behavior, the URL might not always be accessible after a period of time.

This is expected behavior and does not indicate an error in the Docker configuration or the project setup.
